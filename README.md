# INCLUDE
El programa #include es un itinerario que forma, capacita y facilita el acceso 
al empleo, mejorando la inclusión laboral de personas con discapacidad. A 
través de la formación en ciberseguridad, acompañamiento laboral y conexión 
con empresas del sector, el programa prepara a los participantes para acceder 
al mercado de trabajo en un ámbito con alta demanda. También les proporciona 
las herramientas necesarias para desarrollar habilidades técnicas y 
profesionales, aumentando sus posibilidades de empleo.
